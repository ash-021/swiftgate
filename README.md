# SwiftGate — Hospitality Tech PWA Prototype

> Zero-Download Operating System for Modern Hospitality  
> Built for IIT Bombay Eureka! Demo · Next.js 14 · TypeScript · Tailwind CSS

---

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

---

## 📐 Architecture

```
/                  → B2B SaaS Landing Page (Desktop)
/demo/guest        → Interactive Mobile PWA Guest Flow
```

### Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Dark Slate theme)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **QR Code**: qrcode.react

---

## 🏨 Guest Flow (5-Step State Machine)

| Step | Name | Description |
|------|------|-------------|
| 1 | Welcome | Reservation summary & hotel greeting |
| 2 | Biometric Verification | ID upload + selfie with PMS write simulation |
| 3 | Monetized Upsells | Toggleable upgrades with live price calculator |
| 4 | Digital Concierge | F&B menu, cart drawer, payment toggle |
| 5 | Order Confirmation | Status timeline with kitchen tracking |
